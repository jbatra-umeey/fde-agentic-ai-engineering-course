# Customer discovery worksheet

Use fictional or approved anonymized information in a public portfolio.

| Field | Your evidence |
|---|---|
| Sponsor, end user and operator | To complete |
| Workflow trigger and desired output | To complete |
| Current manual steps and exceptions | To complete |
| Measured baseline and sample period | To complete; distinguish assumptions |
| Proposed success metric and threshold | To agree with sponsor |
| Cost of incorrect, late or missing output | To complete |
| Systems, API owners and access dependencies | To complete |
| Data classification and permitted model destinations | To complete |
| Read/write permissions and reviewer | To complete |
| Non-goals and prohibited actions | To complete |
| Pilot users, volume and duration | To complete |
| Rollback trigger and operational owner | To complete |

## Hypotheses to test

For each hypothesis: state the assumption, cheapest validation, evidence needed, owner and due date. A framework preference is not evidence.

## Definition of the first complete slice

Write one paragraph describing input, trusted identity, evidence, decision, review, effect and observable outcome. Attach the relevant module diagrams and explain every external dependency.
